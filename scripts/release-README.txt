Moondrop for Windows {{VERSION}} - {{VARIANT}} (Windows x64)

{{RUNTIME}}

Extract the ZIP before launching Moondrop.exe.
Portable is the recommended download for most users.
Slim needs .NET 10 Desktop Runtime x64, not just the plain .NET Runtime.
If it is missing, Microsoft's launch prompt opens the runtime download page.
Run the downloaded Desktop Runtime installer, then reopen Moondrop.exe.
The .NET SDK is not required. The runtime is not silently installed.

Both downloads are the same app with Equalizer, Presets, and Settings.
Apply changes updates active device settings and verifies readback.
Save to device is a separate device-memory operation.
Local presets and settings stay in the app's existing per-user storage.
Portable means no .NET installation; it does not move settings beside the EXE.

For a hardware-free preview, launch: Moondrop.exe --demo
No physical-device verification is implied by software packaging tests.
